Sentiment Analyzer AI
A simple Machine Learning project that predicts whether a sentence expresses positive or negative sentiment.

Features
Text sentiment analysis
TF-IDF Vectorization
Logistic Regression
Interactive command-line interface
Tech Stack
Python
Scikit-Learn
TF-IDF
Logistic Regression
Installation
pip install -r requirements.txt
Run
python main.py
Example
Input:

I love this movie
Output:

Positive 😊
